# EzTrip 行程演示

这是一个纯静态、可部署到 GitHub Pages 的点击演示。页面使用已经跑好的演示数据和预算参考区间，展示：

- 固定的旅行输入与需求确认表格；
- 北京 2 日行程时间线；
- 与当前行程关联的预算参考；
- 雨天室内候选推荐；
- 用户确认后仅调整受影响日期；
- 调整前后对比、刷新恢复与演示重置。

## 本地查看

直接打开 `index.html` 即可使用。为了获得与 GitHub Pages 更接近的 HTTP 环境，也可以在仓库根目录运行：

```powershell
python -m http.server 4173 --directory portfolio-demo
```

然后访问：

```text
http://127.0.0.1:4173/
```

## 演示路径

1. 查看固定的用户输入，点击“生成行程”；
2. 等待约 1.2 秒，查看整理后的日期、预算、人数和偏好表格；
3. 确认需求，等待约 0.8 秒进入行程；
4. 展开任意活动，查看路线、推荐理由和数据来源；
5. 点击“查看雨天方案”；
6. 对比调整前后，确认仅第 2 天发生变化；
7. 点击“确认调整”，等待约 0.8 秒，再切换版本检查差异；
8. 刷新页面确认状态恢复，或点击“重新开始”清除状态。

## 数据边界

- 页面只读取本地演示数据，不会请求实时服务。
- 雨天替换关系为：`天坛公园 → 首都博物馆`、`景山公园 → 北京天文馆`。
- 原方案和调整后的预算区间均为已经冻结的演示快照。
- 金额不代表实时房价、票价、库存、预订结果或成交价。
- 当前演示只支持北京 2 日预设案例。
